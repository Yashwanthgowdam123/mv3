Put your photos in this folder (exact file names used by data.js):

profile.jpg   - main portrait (about 4:5, e.g. 800x1000)
father.jpg    - father
mother.jpg    - mother
sister.jpg    - sister
gallery-1.jpg ... gallery-6.jpg - slideshow photos

Keep each image under ~500 KB. To use different names or more/fewer
gallery photos, edit the paths in data.js.
